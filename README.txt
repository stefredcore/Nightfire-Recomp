007 NIGHTFIRE - PC VERSION

You need: your own 007 Nightfire Xbox disc (European or North-American), extracted.

The easy way: run Nightfire-Setup.exe, choose the disc's default.xbe and a folder.
It brings everything it needs to build the game and installs nothing else.

From this folder instead (needs Visual Studio and Python, see README.md):
1. Create a folder named "game" in this folder.
2. Copy the contents of the disc into it (game\default.xbe must exist).
3. Double-click build.bat and wait until it says "Done".

Play with "Nightfire Launcher.exe". It lets you choose the mode:
   Original - the game as on the console, with a controller only
   Enhanced - with mouse and keyboard as in the PC version (keys in mkb.ini,
     F9 switches them off and on)
